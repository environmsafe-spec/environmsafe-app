# منصة التعلّم عن بُعد — مدارس القمة النموذجية، تعز (الصف السادس)

منصة عربية بسيطة للتعلّم عن بُعد: دروس، صفحات الكتاب المدرسي، فيديو، صوتيات، ملفات، تمارين واختبارات تُصحَّح تلقائياً، ومتابعة للمدرس والمدير.
تعمل من **المتصفح** على أي جهاز، ومن **تطبيق أندرويد** (`public/download/qimmah.apk`).
مجانية بالكامل: تعمل على الخطة المجانية من Cloudflare (Workers + قاعدة بيانات D1 + تخزين R2)، دون أي خدمة مدفوعة.

## ما الموجود في المنصة

| | التلميذ | المدرس | المدير |
|---|:-:|:-:|:-:|
| قراءة الدروس وصفحات الكتاب، مشاهدة الفيديو، سماع الصوت | ✅ | ✅ | ✅ |
| حل التمارين والاختبارات ورؤية النتيجة وتصحيح الأخطاء | ✅ | معاينة | معاينة |
| إضافة/تعديل/حذف/ترتيب: المواد، الوحدات، الدروس، الفيديو، الصوت، الملفات، الروابط، صفحات الكتاب | — | ✅ | ✅ |
| إنشاء الاختبارات: اختيار من متعدد، صح وخطأ، إجابة قصيرة؛ درجة النجاح؛ عدد المحاولات | — | ✅ | ✅ |
| نشر أو إخفاء أي درس أو اختبار | — | ✅ | ✅ |
| تقدّم كل تلميذ ونتائج كل اختبار | نتائجه فقط | ✅ | ✅ |
| الإعلانات | قراءة | ✅ | ✅ |
| الحسابات: إنشاء، إيقاف، حذف، تغيير كلمة المرور، طباعة بطاقات الدخول، سجل العمليات | — | — | ✅ |

**المحتوى الجاهز:** كتاب الرياضيات للصف السادس — الجزء الأول (وزارة التربية والتعليم): 4 وحدات، 29 درساً. لكل درس شرح مبسّط وصفحاته من الكتاب وتمرين (5–6 أسئلة)، ولكل وحدة اختبار. المجموع 218 سؤالاً. يستطيع المدرس تعديل كل شيء.
لا توجد فيديوهات أو تسجيلات صوتية جاهزة. يضيفها المدرس من **المحتوى ← الدرس ← إضافة محتوى**.

**الحسابات:** مدير (`principal`)، ومدرس (`teacher`)، و30 تلميذاً أسماء مستخدميهم من `601` إلى `630`، وكلمة مرور كل تلميذ 6 أرقام.
**كلمات المرور ليست في هذا المستودع لأنه عام.** هي في الملف `.secrets/CREDENTIALS.md` الذي يُنشأ عند التشغيل، ويستطيع المدير تغييرها وطباعة بطاقات جديدة من داخل المنصة.

## التشغيل على الإنترنت (مرة واحدة)

تحتاج حساباً مجانياً في Cloudflare وجهاز كمبيوتر عليه Node.js 20 أو أحدث.

```bash
cd qimmah-lms
npm install
npx wrangler login        # يفتح المتصفح لتسجيل الدخول إلى Cloudflare
npm run deploy            # ينشئ قاعدة البيانات والتخزين، ويرفع المحتوى والحسابات، وينشر الموقع
```

- العنوان المضبوط: **https://qimmah.environmsafe.com** (يُنشأ تلقائياً إذا كان النطاق environmsafe.com في حساب Cloudflare نفسه). إذا لم يكن كذلك ينشر السكربت على عنوان مجاني `https://qimmah-lms.<اسم-حسابك>.workers.dev`، ويُكتب هذا العنوان مرة واحدة في التطبيق من **إعدادات الخادم**.
- إذا طلب Cloudflare تفعيل R2 فعّله مرة واحدة من لوحة التحكم (R2 ← Get started). الخطة المجانية فيها 10 غيغابايت.
- إذا كان الملف `.secrets/credentials.json` موجوداً تُستخدم كلمات المرور الموجودة فيه، وإلا تُنشأ كلمات مرور جديدة.
- إعادة تشغيل `npm run deploy` تحدّث الموقع فقط ولا تمسح أي بيانات.

**أو تلقائياً من GitHub:** أضف في إعدادات المستودع ← Secrets الأسرار `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID` و`QIMMAH_CREDENTIALS` (محتوى `.secrets/credentials.json`). بعدها يُنشر الموقع مع كل تحديث لمجلد `qimmah-lms/` على `main`، أو يدوياً من Actions ← Qimmah LMS deploy.

## تطبيق أندرويد

- الملف: `public/download/qimmah.apk` (حجمه نحو 100 كيلوبايت، موقَّع). ويُحمَّل أيضاً من رابط «تحميل تطبيق أندرويد» في صفحة الدخول.
- يفتح المنصة مباشرة، ويحتفظ بتسجيل الدخول، ويرفع الملفات من الهاتف، ويعرض الفيديو بملء الشاشة، ويعرض رسالة «لا يوجد اتصال» مع زر إعادة المحاولة عند انقطاع الإنترنت.
- التحديثات في المحتوى والموقع تظهر في التطبيق فوراً دون تثبيت نسخة جديدة.
- طريقة البناء موضحة في `android/README.md`. **مفتاح التوقيع غير موجود في المستودع.** احتفظ بنسخة آمنة منه، فبدونه لا يمكن إصدار تحديث للتطبيق.

## دليل سريع للمدرس

1. ادخل بحساب `teacher` ثم اضغط **المحتوى** ← الرياضيات.
2. **درس جديد:** «+ درس جديد» تحت الوحدة، ثم «إضافة محتوى» واختر: نص وشرح، فيديو، تسجيل صوتي، ملف، رابط، صفحات الكتاب.
   - **الفيديو:** يمكن رفعه من الهاتف (حتى 95 ميغابايت)، والأفضل وضع رابط يوتيوب (غير مُدرج) أو Google Drive لأنه أخف على إنترنت التلاميذ.
   - **الصوت:** سجّل الشرح بالهاتف ثم ارفعه.
3. **تمرين أو اختبار:** «+ تمرين جديد» داخل الدرس، أو «+ اختبار للوحدة»، ثم «+ سؤال جديد».
4. الدرس الجديد يكون **مخفياً** حتى تضغط **«📢 نشر للتلاميذ»**.
5. **التلاميذ** ← اضغط اسم التلميذ لترى دروسه ونتائجه. وفي صفحة كل اختبار زر **📊 النتائج**.

## دليل سريع للمدير

- **المستخدمون:** تعديل الأسماء (اكتب الأسماء الحقيقية للتلاميذ)، 🔑 كلمة مرور جديدة، إيقاف الحساب أو تفعيله، إضافة تلميذ.
- **🖨️ بطاقات الدخول:** تنشئ كلمات مرور جديدة للتلاميذ المختارين وتطبعها بطاقاتٍ تُقصّ وتوزَّع.
- **🧾 السجل:** من دخل ومتى، وكل تغيير في الحسابات والمحتوى.
- **إذا نسي المدير كلمة مروره:** `npm run reset-password -- principal`

## الأمان

- كلمات المرور مخزّنة مشفّرة (PBKDF2-SHA256 مع ملح عشوائي) ولا يمكن قراءتها.
- الجلسة في ملف تعريف ارتباط (cookie) من نوع `HttpOnly` و`Secure` و`SameSite`. تنتهي جلسة التلميذ بعد 30 يوماً، والمدرس بعد 14 يوماً، والمدير بعد 7 أيام.
- بعد 5 محاولات دخول خاطئة يُقفل الحساب 15 دقيقة، وبعد 30 محاولة من نفس الجهاز يُقفل الجهاز.
- كل صلاحية يتحقق منها الخادم، فلا يستطيع التلميذ تعديل المحتوى ولا الدرجات، ولا رؤية نتائج غيره، ولا رؤية الإجابات الصحيحة قبل التسليم.
- الحماية من تزوير الطلبات (CSRF) وسياسة أمان المحتوى (CSP)، ورفض الملفات الخطرة عند الرفع، ولا تُفتح الملفات المرفوعة إلا لمن سجّل الدخول.
- 70 اختباراً آلياً في `scripts/smoke-test.mjs` تغطي الصلاحيات والتصحيح والرفع والقفل.

## For developers (English)

- **Stack:** Cloudflare Worker (`src/worker.js`, no framework) + D1 (SQLite, `migrations/`) + R2 (uploads) + Workers Static Assets (`public/`: vanilla-JS SPA, RTL, service worker). There is no build step.
- **Local:** `npm install && npm run setup:local && npm run dev` → http://localhost:8787 (local D1/R2 emulation, no account needed). `npm test` runs the API checks against the dev server. Run `npm run setup:local` again afterwards to reset the data.
- **Seed:** `seed/content.json` (course content, safe to edit) plus generated accounts → `.secrets/seed.sql`. `.secrets/` is git-ignored; never commit it (the repository is public).
- **Hashing:** `PBKDF2_ITERATIONS` in `wrangler.toml` is 20000, so a login fits the free plan's 10 ms CPU limit. Raise it to 100000 on a paid plan; existing hashes keep working because each stores its own iteration count.
- **Book pages:** `public/book/math6/pNNN.jpg` (printed page number), rendered from the MoE PDF. A `book` item stores `{book, from, to}`.
- **Android:** `android/` holds a native WebView wrapper with the default URL as a Gradle property. See `android/README.md`.
